# ADR-0004：按当前需要帮助读者跟随信息与开始行动

日期：2026-10-13。状态：本地实现，未发布。扩展 Aptum 的读者判断，不改变 humanizer-zh 的明确启用条件或长期档案权限。

## 问题与依据

用户要求吸收有价值的 ADHD 表达能力，同时保持主文件简洁和动态判断。现有 Aptum 已处理知识、背景和交接遗漏，但“每句都懂却跟不上”“中断后忘记进度”“不知道先做什么”也会阻碍完成任务。

参考 `ayghri/i-have-adhd` 的固定提交 [1ecea199](https://github.com/ayghri/i-have-adhd/blob/1ecea1993b7fce257ffbd686c070948b5e07eda6/skills/i-have-adhd/SKILL.md)。其行动优先、步骤划分、状态恢复与控制旁支值得借鉴；这是对写作方法的选择，不作为医学依据或效果证据。

## 选择与代价

主文件增加一个判断段落、一个介入场景，并链接按需参考。详细方法独立编写在 [attention.md](../../references/attention.md)，不复制上游全部规则，不新增会话模式或自动钩子。

根据当前反馈选用信息分组、明确顺序或状态恢复；完整交付仍保留条件、选项、风险、授权与未验证状态。Agent 继续完成获准的工作，不能用“给用户下一步”替代实际执行。

不采用诊断假设、默认持续整场会话、固定五项上限、每轮重述进度或无依据的时长估计。长期偏好仍只按原有确认规则保存，记录有范围的表达习惯，不保存健康标签。

此选择保留泛化空间，代价是需要模型判断具体阻碍；不能保证每次触发准确或一定优于无 Skill。若加入的提醒导致重复、藏起关键选项或把工作推回用户，应优先修正或删减相应指导。

## 验证与复审

[八个行为用例](../../evals/attention.yaml)覆盖优先事项、操作顺序、中断恢复、完整比较、Agent 代做、纯解释、临时反馈与偏好覆盖。[场景核对](../../examples/attention-scenarios.md)明确区分构造素材、实现者生成的输出和自查，未作独立模型盲测。

复审依据是读者能否找到重点、开始正确动作、恢复状态及保留关键事实，不看列表数量、篇幅下降或是否像固定文风。重复出现误适配时补对应案例，不扩大为普遍模板。
