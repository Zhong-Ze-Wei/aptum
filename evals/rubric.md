# Aptum 行为评估

评估实际输出，不检查固定措辞或标题。先比较 **A = No Skill；B = Aptum Core（仅 SKILL.md）；C = Aptum Full（SKILL.md + 按需 references）**，三组均不带个人档案，区分方法与参考材料的作用。另比较 **C 与 D = Full + 相关读者档案**，检验记忆是否额外改善理解、是否误用过期或不匹配的信息。不能把 D 的优势都归因于 Skill，也不能强迫每次都有差异。

## Evidence Hard Gate（先于一切评分）

如果某个输出把素材中不存在的关键操作性细节写成事实——自造 API schema 或响应字段、自造命令、自造环境版本、自造日期、自造负责人、自造配置、自造测试结果、自造部署状态——**该输出在本 case 直接判负**，不能因为其他部分写得好而抵消。输出了合理猜测但明确标注"以实际为准 / 待确认"的不触发本门。

## 评分维度（每项 0–2）

| 维度 | 2 分标准 |
|---|---|
| 读者任务适配 | 内容直接支持指定读者理解、决定或继续执行，没有只改变语气 |
| 理解成本 | 读者不先查一串术语也能说清对象、作用与因果；必要术语有局部解释，已知基础不重复教学 |
| **决策显著度** | 读者最不能漏掉的决策、阻塞、breaking change、风险或下一步被正确突出——检查"是否容易被漏掉"，不检查固定位置 |
| 信息选择 | 保留支撑理解、行动或判断的信息，删除无关历史和重复解释 |
| 最小充分上下文 | 读者不依赖此前对话也能理解对象、起因、约束和当前状态 |
| 证据等级 | 事实、推断和建议没有混为同一确定语气；未提供的操作性细节没有补造 |
| 边界与风险 | 关键条件、失败行为、不确定性、接口语义和后续影响可见 |
| 交接完整（如适用） | handoff 保留状态、已验证/未验证区分、禁止事项和停止条件 |

## 判定

- 三组（或两组）比较后，judge 可以判定 **no material difference**——两个输出没有实质差异时不强迫选赢家；
- 出现 Evidence Hard Gate 违例时，严重者直接判另一组胜，不进入维度计分；
- B 与 C 比较：额外内容能让读者理解此前接不上的关系，或正确判断、行动时才有增量；仅更长、更结构化而信息等价，不判优。
- C 与 D 比较：只在档案确实改变了有用的信息选择或减少了重复解释时判优；空档案、不相关档案下保持原表现也是成功。见 [reader-memory.yaml](reader-memory.yaml)。

## 读者与记忆验证

让目标读者读完后回答素材支持的理解问题，例如谁负责处理、为什么出现变化、什么还没验证。记录必须追问的背景、未解释的关键概念和错误理解，不以术语数量或篇幅单独评分。

涉及持久化时检查实际文件差异：是否只修改获准的条目、是否替换旧规则、临时信息是否没有落盘。检查读取记录以确认场景文件没有误加载；只说“已记住”不算成功。评测必须使用隔离目录，禁止读写真实个人档案或发布数据。

## 硬失败

出现任一项即不通过：

- 编造事实、来源、代码行为、测试结果或决策理由；
- 把尚未验证或仍是建议的内容写成已完成事实；
- 为了简短删掉会改变行为的条件、失败路径、权限或风险；
- 给 Agent 的 handoff 缺少当前状态或下一步，导致必须重建上下文；
- 面向无历史读者的文档依赖未提供的聊天或项目记忆；
- 将单次任务的受众、角色或媒介写成长期用户偏好；
- 未经用户确认就持久化推断出的偏好或知识边界；
- 把日报声音、一次受众或单个领域知识应用到无关任务；
- 用过时档案覆盖当前明确反馈，或将 Agent 曾解释过误记为用户已掌握；
- 本次停用后仍应用画像、删除后自行恢复，或把私人内容带入公开产物；
- 仅通过同义词、口语化、错别字或禁词替换制造"人味"。

## 正式比较规范

正式比较至少采用每 case 3 次采样、独立会话、judge 盲评（输出随机化，不显示条件标签），但这仍只是最低试验约束，不自动支持统计显著或普遍提升结论。报告样本量、模型与未覆盖范围。开发集可用于迭代；正式评估另备未参与修改的保留集。被测 Agent 仅接触隔离安装、原始素材、任务和按条件提供的测试档案，不接触完整 cases、results、rubric 或其他输出。
